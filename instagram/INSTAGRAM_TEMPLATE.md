# Lexi's Selection Instagram Carousel Template

Use this whenever the user asks for an Instagram post “like last time” or “按模板做”.

## Canvas

- Size: 1080 × 1350 px.
- Output: PNG carousel slides.
- Language on image: English only.
- Overall feeling: clean boutique sale note, not loud ad flyer.

## Colors

- Background: `#F8F1E8`
- Card / image mat: `#FFFDF8`
- Main text: `#1E332F`
- Terracotta accent: `#C66A52`
- Muted gray: `#756F68`
- Hairline border: `#DFC7B9`
- Small gold label: `#B08A52`

## Fonts

Use these exact fonts unless the system truly cannot render them.

- Large elegant title words: `Didot`, regular weight.
- Discount / big serif accent: `Didot`, regular weight.
- Header “Lexi’s Selection”: `Avenir Next`, Demi Bold Italic.
- Subtitle / spaced caps / small labels: `Avenir Next`, Demi Bold, with wide tracking.
- Body notes and small footer text: `Avenir Next`, Medium or Demi Bold.
- Do not switch to Playfair, Bodoni, Georgia, Times, or random Canva-style fonts.

Reference hierarchy:

- Biggest visual words: Didot.
- Everything informational: Avenir Next.
- No more than these two font families in one carousel.

## Fixed header

Use on every designed slide:

- Burger icon at top left, about 44–52 px wide.
- “Lexi’s Selection” beside icon, dark green, italic.
- Subtitle below: `CURATED BOUTIQUE DEALS`, spaced caps.
- Thin divider line under header.

Approximate placement:

- Outer border card: x 44, y 48, w 992, h 1258, radius 36.
- Burger: x 105, y 88, w 48.
- Title: x 170, y 90.
- Subtitle: x 200, y 150.
- Divider: x 110, y 195, w 860.

## Cover slide layout

Purpose: one clear sale note.

Structure:

1. Header.
2. Small label: `S A L E   N O T E`.
3. Main title, 1–2 lines max. Example: `Recent Sale Buys`.
4. Discount line, large terracotta. Example: `70%+ OFF`.
5. Supporting line. Example: `all under 30% of retail`.
6. One large hero image or a tidy 2-photo collage.
7. Optional tiny note at bottom. Example: `Sizes and stock move quickly. Always confirm at checkout.`

Rules:

- Do not crowd store names on the cover.
- Do not let title words overlap.
- If using a real item photo, keep it large enough to see texture.
- If adding store/brand info, place it directly on the image as a small translucent pill, not as a crowded text block below.

## Product / find slide layout

Use for individual item or store examples:

1. Header.
2. Small label: `S A L E   F I N D` or `RECENT FIND`.
3. Large product/photo frame.
4. Overlay pill on the image if needed:
   - top-left or bottom-left;
   - first line: brand;
   - second line: store;
   - optional third line: discount.
5. Bottom note area can show one short line only.

Image rules:

- Lay-flat/haul photos: use `cover`, crop neatly, keep the item central.
- Tall single-item photos: use `contain`, keep full item visible.
- Rotate sideways photos before layout.
- Avoid tiny product images; if the item becomes too small, crop closer.
- Keep margins even.

## Common fixes before exporting

- Check all text fits inside the card.
- Check no sentence is cut off.
- Check fonts match the previous template.
- Check brand/store names are correct.
- Check discount language is factual and not claiming an active promo if it is only a past purchase.
- No direct clickable-looking URL on image if Instagram link restrictions are active.
