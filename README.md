# Lexi's Selection

A local kidswear deal finder for tracking good brands at better prices.

## What it does

- Finds discounted kidswear and shoes from selected boutiques.
- Filters by brand, source, discount, type, gender, clothes size, and shoe size.
- Caches product data locally for the day.
- Marks new finds after refresh.
- Compares prices with the previous refresh.

## Run Locally

```bash
npm start
```

Then open the local URL printed in the terminal, usually:

```text
http://localhost:5173
```

## Notes

Local cache and generated output files are intentionally ignored by git.
